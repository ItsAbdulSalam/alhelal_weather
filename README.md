# 🌤️ Alhelal Weather App

A modern, responsive cross-platform weather application built with **Flutter** and **Dart**, following **Clean Architecture** principles and **BLoC/Cubit** pattern.

## 📱 Features
- **Real-Time Weather Metrics:** Live temperature, wind speed, humidity, and atmospheric conditions.
- **7-Day Weather Forecast:** Comprehensive weekly projections and daily breakdowns.
- **Global City Search:** Instant query handling for global locations.
- **Dynamic Glassmorphism UI:** Smooth gradients shifting adaptively based on ambient weather states.
- **Robust Error Handling:** Pull-to-refresh reload triggers and clean offline feedback.

## 🛠️ Tech Stack & Architecture
- **Framework:** [Flutter](https://flutter.dev) (Dart)
- **State Management:** BLoC / Cubit Pattern
- **Architecture:** Clean Architecture (Data, Domain, Presentation layers)
- **Networking:** RESTful API integration & Type-safe JSON serialization
- **Deployment:** Google Play Console (AAB release builds)
